أصلح مشكلة عرض النص العربي داخل PDF النهائي.

المشكلة الحالية:
بعد تعبئة الحقول وتوليد الموافقة، النص العربي يظهر بفراغات غير طبيعية بين الحروف والكلمات، رغم استخدام خط Noto Naskh Arabic.

هذه ليست مشكلة font path فقط، بل مشكلة Arabic shaping + RTL/Bidi عند الكتابة بواسطة pdf-lib.

المطلوب:

1. لا تستخدم:

* reverse() البسيط للنص العربي.
* تقسيم النص إلى حروف وكتابتها حرفاً حرفاً.
* characterSpacing موجب.
* إضافة مسافات يدوياً.
* Helvetica كـ fallback للنص العربي.

2. أنشئ helper مركزي مثل:
   prepareArabicText(text: string): string

ويقوم بـ:

* اكتشاف وجود أحرف عربية.
* تطبيق Arabic shaping حتى تتحول الحروف إلى أشكالها المتصلة الصحيحة.
* تطبيق Unicode Bidirectional processing للنص العربي RTL.
* الحفاظ على الأرقام والمسافات وعلامات الترقيم بالترتيب الصحيح.
* عدم تغيير النص الإنجليزي.

استخدم مكتبة موثوقة متوافقة مع TypeScript/Node مثل:

* arabic-reshaper أو بديل مناسب للتشكيل.
* bidi-js أو بديل يطبق Unicode Bidirectional Algorithm.

لا تستخدم text.split("").reverse().join("") لأنه يفسد الأرقام والكلمات المختلطة.

3. قبل page.drawText:

* مرّر كل قيمة عربية من خلال prepareArabicText.
* اضبط characterSpacing على 0.
* لا ترسم كل حرف منفصلاً.
* ارسم النص الناتج مرة واحدة.

4. محاذاة RTL:

* احسب عرض النص بعد تشكيله:
  const textWidth = font.widthOfTextAtSize(preparedText, fontSize)
* ضع النص من جهة اليمين داخل مربع الحقل:
  const padding = 3
  const textX = fieldX + fieldWidth - textWidth - padding
* لا تستخدم x كنقطة بداية ثابتة للنص العربي.
* تأكد أن textX لا يقل عن fieldX + padding.

5. النص المختلط:
   اختبر النصوص التالية تحديداً:

* أحمد الزهراني
* علاج جذور الأسنان
* المريض أحمد لديه 1 ضرس
* رقم الهوية 1234567890
* موعد الإجراء 10/06/2026
* المريض بحاجة إلى علاج Root Canal

يجب أن تظهر الكلمات العربية متصلة، والأرقام بترتيبها الصحيح، بدون فراغات بين الحروف.

6. الحل الاحتياطي الأكثر ثباتاً:
   إذا لم ينجح Arabic shaping داخل pdf-lib بشكل موثوق، استخدم هذا الحل بدلاً منه للنصوص العربية:

* أنشئ SVG أو PNG شفاف لكل قيمة عربية.
* استخدم خط Noto Naskh Arabic.
* اضبط:
  direction="rtl"
  text-anchor="end"
  unicode-bidi="plaintext"
* حوّل SVG إلى PNG باستخدام sharp أو أداة متوافقة مع Node.
* ادمج الصورة داخل PDF باستخدام pdfDoc.embedPng.
* ضع الصورة داخل نفس إحداثيات template_field.
* استخدم هذا الأسلوب فقط للحقول العربية، واستمر باستخدام drawText للنصوص الإنجليزية والأرقام عند الحاجة.

الحل بالصورة مقبول لأنه يحافظ على شكل العربية الصحيح داخل PDF، حتى لو أصبح النص غير قابل للتحديد.

7. Multiline:

* لا تقسّم النص العربي حسب عدد الأحرف فقط.
* قسّم حسب الكلمات وقياس عرض كل سطر.
* كل سطر يجب أن يمر بعملية shaping وbidi بشكل مستقل.
* ارسم الأسطر من اليمين إلى اليسار داخل مساحة الحقل.
* لا تضف فراغات بين الحروف.

8. الاختبارات:

* ولّد PDF باسم مريض عربي كامل.
* اختبر كلمة واحدة.
* اختبر جملة عربية.
* اختبر جملة عربية مع أرقام.
* اختبر عربي + إنجليزي.
* اختبر multiline.
* افتح PDF الناتج فعلياً وتأكد بصرياً أن:

  * الحروف متصلة.
  * لا توجد مسافات بين حروف الكلمة.
  * الكلمات مرتبة من اليمين لليسار.
  * الأرقام ليست معكوسة.
  * النص لا يخرج من مربع الحقل.
* شغّل Typecheck للـ backend والـ frontend.

لا تعتبر الإصلاح مكتملًا بمجرد نجاح API.
يجب فحص ملف PDF الناتج بصرياً ومقارنته بالنص الأصلي.
