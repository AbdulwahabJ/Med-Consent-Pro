Doctor:

Consent Template:
Each consent template belongs to one doctor.

* Template name
* Doctor
* PDF file
* Active/inactive
* Notes optional

PDF Field Mapping:
This is required.

Admin uploads a blank consent PDF, then visually maps fields on the PDF.

Supported mapped fields:

* Patient name
* File number
* Mobile number
* National ID
* Date
* Text
* Multiline text
* Checkbox
* Patient signature

For each field store:

* label
* field key
* field type
* required true/false
* page number
* x
* y
* width
* height
* font size
* display order

Fill Consent:
The staff should NOT fill directly on the PDF.

The staff should fill a simple tablet-friendly form generated from the mapped fields.

Basic patient info is entered only during consent filling:

* Patient name
* File number
* Mobile optional
* National ID optional

Do not create a full patient profile.
